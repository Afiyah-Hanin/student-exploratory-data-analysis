# Student Performance Analysis

This project performs Exploratory Data Analysis (EDA) on a student performance dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objective
To analyze student data and understand different factors related to student performance.

## Dataset
The dataset contains information about students, including demographic details, study habits, family background, and academic scores.

## Project Work
- Data loading
- Data cleaning and inspection
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Analysis of student performance

## Files
- `Student_Performance_Analysis_EDA_Project.ipynb` — Main project notebook

## Conclusion
The project uses data analysis and visualization techniques to explore patterns in student performance.
