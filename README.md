# Student Exploratory Data Analysis

This project explores and analyzes student-related data using Python.

## About the Project

The notebook contains data analysis and visualization of student-related information. It uses Python libraries to understand the data and find useful patterns.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Project File

- `student_exploratory_data_analysis.ipynb` - Main Jupyter Notebook containing the analysis.

## How to Run

1. Download the `.ipynb` file.
2. Open it using Google Colab or Jupyter Notebook.
3. Run the cells to view the analysis and results.
